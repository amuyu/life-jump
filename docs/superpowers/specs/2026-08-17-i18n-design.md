# Life Jump — 다국어(i18n) 설계

작성일: 2026-08-17
상위 문서: `2026-08-15-life-jump-design.md`. 관련: `2026-08-17-touch-controls-design.md`(오버레이 문구), `docs/toss-app-info.md`

## 1. 개요

한국어 단일이던 UI 를 **한국어 + 영어**로 만든다. 앱인토스는 한국 사용자가 대부분이지만 Play 스토어는
기기 언어를 따르므로 영어 하나는 있어야 한다. 구조는 언어 추가가 사전 파일 하나로 끝나게 두되,
지금 세 번째 언어는 만들지 않는다.

### 핵심 결정

| 항목 | 결정 |
|---|---|
| 방식 | 자체 경량 모듈 `src/i18n/` — 사전 객체 + `t(key, params?)`. 의존성 없음 |
| 언어 | `ko`(기준), `en`. `Locale = 'ko' \| 'en'` |
| 선택 | 자동(`navigator.language`) + 로비 헤더 `KO / EN` 토글. 선택은 세이브에 저장 (`locale: Locale \| null`, null = 자동) |
| 데이터 이름 | 옷·업그레이드·소모품·구간의 `name`/`desc` 는 **i18n 키**로 (id 는 그대로 → 세이브 호환) |
| 퀴즈 | 언어별 파일 `quiz.ko.json` / `quiz.en.json`. **같은 id·difficulty·answer 인덱스**, 문구만 다름. 한국 특정 문제 3개는 영어판에서 다른 상식 문제로 대체 |
| 복수형 | 사전 값에 `"{n} coin\|{n} coins"` — `n === 1` 이면 앞, 아니면 뒤. 이 프로젝트에 필요한 복수 처리의 전부 |
| 한국어 조사 | `ko.ts` 가 `particle(word, '을/를')` 헬퍼를 export. `shell.ts` 의 `withObjectParticle` 이 거기로 이동 |
| HUD(캔버스) | 숫자·아이콘뿐 — 언어 무관, 변경 없음 |
| `game/` 계층 | `quiz.ts` 만 `questionsFor(locale)` 시그니처 변경. DOM/저장은 여전히 안 봄 |

### 비목표

- 일본어 등 3번째 언어 (사전 파일 추가로 가능하도록만)
- 스토어/콘솔 문구 영어판 (`toss-app-info.md` 는 한국어 유지)
- RTL, 날짜/숫자 로케일 포맷 (게임에 날짜 없음, 숫자는 `m`·개수뿐)
- i18next 등 라이브러리 (번들 20KB 게임에 40KB 런타임은 과함)
- 서버 사이드 번역, 원격 사전

## 2. 모듈 (`src/i18n/`)

```
src/i18n/
  index.ts    Locale, t(), setLocale(), getLocale(), detectLocale(), onLocaleChange(), particle()
  ko.ts       export const ko = { 'lobby.play': '게임 시작', … } as const   ← 키 집합의 기준
  en.ts       export const en: Dict = { … }   Dict = Record<keyof typeof ko, string>  ← 키 누락/오타 = 컴파일 에러
```

### 2.1 인터페이스

```ts
export type Locale = 'ko' | 'en'
export type MsgKey = keyof typeof ko
export type Params = Record<string, string | number>

/** 현재 언어의 문구. {name} 치환, "a|b" 는 params.n 으로 단수/복수 선택. 없는 키는 키 문자열을 돌려주고 dev 에서 console.warn */
export function t(key: MsgKey, params?: Params): string
export function getLocale(): Locale
/** 저장·DOM lang 갱신은 호출자(main) 몫. 여기서는 사전만 바꾸고 구독자에게 알린다 */
export function setLocale(locale: Locale): void
/** navigator.language 가 'ko' 로 시작하면 ko, 아니면 en. navigator 가 없으면(테스트) en */
export function detectLocale(nav?: { language?: string }): Locale
export function onLocaleChange(cb: (l: Locale) => void): () => void
/** 한국어 조사. ko 가 아니면 word 그대로 */
export function particle(word: string, kind: '을/를' | '이/가' | '은/는'): string
```

### 2.2 규칙

- **키 이름**: `screen.element` — `lobby.play`, `quiz.rewardTitle`, `result.retry`, `outfit.striped`, `zone.sky`.
  문자열 값이 아니라 의미로. 같은 문구가 두 화면에 나와도 화면별 키를 따로 둔다 (한 화면만 바꿀 수 있게).
- **보간**: `{n}`, `{name}` 같은 `{ident}` 만. 중첩·포맷 지정자 없음.
- **복수**: 값에 `|` 가 있고 `params.n` 이 숫자면 `n === 1 ? left : right`. ko 사전은 `|` 를 쓰지 않는다.
  `|` 가 있는데 `n` 이 없으면 오른쪽(복수)을 쓴다 — 개발 실수가 눈에 띄게.
- **fallback**: 키가 현재 사전에 없으면 ko 사전, 거기도 없으면 키 문자열. (타입이 막지만 런타임 안전망.)
- **`particle`**: 마지막 글자가 완성형 한글이면 받침으로 을/를·이/가·은/는 선택. 아니면 뒤쪽(를/가/는). ko 이외 로케일이면 word 만 돌려준다 — 영어 문장에서 조사가 붙지 않게 사전 쪽 문장이 `{name}` 만 쓴다.
- `t()` 는 순수(사전 조회)라 어디서든 호출 가능. `game/` 은 문구를 만들지 않으므로 import 하지 않는다.

### 3.1 데이터 파일 변경

- `Outfit.name` → `nameKey: MsgKey` (값 `'outfit.striped'` 등). `UPGRADES[i].name/desc`, `CONSUMABLES[i].name/desc` 도 `nameKey`/`descKey`.
  UI 는 `t(outfit.nameKey)`. **id 는 바뀌지 않는다** — `ownedOutfits`, `selectedConsumables` 세이브 호환.
- 구간 이름 표(`lobby.ts`/`records.ts` 의 `{ground:'땅',…}`)는 사전 키 `zone.ground/sky/space` 로 통합.
- `tests/data/outfits.test.ts`, `shop.test.ts` 가 한국어 이름을 비교하면 `t()` 로 기대값을 만들거나 키를 비교하도록 바꾼다.

## 4. 퀴즈

- `src/data/quiz.json` → `quiz.ko.json` (내용 그대로) + `quiz.en.json`.
- `game/quiz.ts`: `QUESTIONS` 상수 대신 `questionsFor(locale: Locale): readonly Question[]`. `pickQuestion(platformY, seen, rng, locale)`. `Locale` 타입만 `i18n/index.ts` 에서 **type import** (값 import 없음 → `game/` 이 사전을 안 끌어옴).
- **id·difficulty·answer 인덱스는 두 파일이 동일**해야 한다. `seenQuizIds` 가 id 기준이라 언어를 바꿔도 이미 푼 문제는 다시 안 나온다.
- 영어판: 37문제 번역 + 한국 특정 3문제 대체(같은 id·난이도·정답 자리):
  - `e04` (answer 2) 한국의 수도 → "What is the capital of Australia?" — `["Sydney", "Melbourne", "Canberra", "Perth"]`
  - `e15` (answer 1) 김치 주재료 → "Which vegetable are pickles usually made from?" — `["Carrot", "Cucumber", "Onion", "Potato"]`
  - `n05` (answer 2) 훈민정음 반포 → "In what year did the Berlin Wall fall?" — `["1987", "1988", "1989", "1991"]`
  (정답 인덱스는 원본과 같다: 2, 1, 2.)
- 테스트: 두 파일 id 집합 동일, id 별 difficulty·answer 동일, choices 4개, 문자열 비어 있지 않음.

## 5. 언어 선택·저장·적용

- `SaveData.locale: Locale | null` 추가. 기본 `null`(자동). `SAVE_VERSION` 3 → 4 (순수 추가, version 만 전진). 병합 시 `'ko'|'en'` 아니면 `null`.
- 시작(main): `setLocale(save.locale ?? detectLocale(navigator))`.
- 토글: 셸 헤더 재화 칩 옆 `KO | EN` 칩 (현재 언어 강조). 클릭 → `save.locale = 선택값; persist(); setLocale(); render()`.
  자동 감지로 돌아가는 옵션은 두지 않는다(YAGNI — 토글로 원하는 언어를 고르면 그게 답).
- `setLocale` 시 main 이 `document.documentElement.lang` 과 `document.title`(`t('app.title')`) 을 갱신.
- 판 중에는 셸이 안 그려지므로 토글도 없다. 판 중 언어가 바뀔 일 없음.
- 퀴즈 모달은 열릴 때 `getLocale()` 로 문제를 고른다.

## 6. 영어 번역 정책

- 게임 UI 영어로 자연스럽게, 직역 아님. 핵심 용어 고정: 실 = **thread**, 코인 = coins, 에너지 = energy, 옷장 = Wardrobe, 상점 = Shop, 기록 = Records, 로비 = Lobby, 구간 = ground / sky / space, 판 = run.
- 버튼: 게임 시작 = Play, 출발! = Go!, 다시 도전 = Try again, 로비로 = Lobby, 착용하기 = Wear, 제작하기 = Craft, 소모품 선택하기 = Choose items.
- 조작 힌트: "왼쪽 밀어서 이동 · 오른쪽 길게 눌러 점프" = "Slide left half to move · Hold right half to jump"; 키보드 = "← → move · Hold Space to jump".
- 복수: `{n} thread` 는 불가산으로 단수 고정, `{n} coin|{n} coins`, `{n} run|{n} runs`.

## 7. 테스트

- `tests/i18n/i18n.test.ts`: 보간, 복수(`n` 1/2/0/없음), fallback(없는 키 → ko → 키), `en` 이 `ko` 와 키 집합 동일(런타임 Object.keys 비교 — 타입만 믿지 않음), `detectLocale('ko-KR'|'en-US'|undefined)`, `particle` 받침 판정과 en no-op, `onLocaleChange` 발화/해제.
- `tests/data/quiz.test.ts`(신규 또는 기존 확장): 두 언어 파일 정합성(4절).
- 기존 UI 테스트에서 한국어 문구를 직접 비교하던 곳(`quizModal`, `shell`, `touchOverlay`, `touchHint`, `outfits`, `shop`) → `setLocale('ko')` 를 명시하고 기대값을 `t()` 로 만들거나 키를 비교. 문구를 고정하던 테스트는 키/구조 검사로 바꾼다.
- `tests/core/storage.test.ts`: v3→v4, `locale` 기본 null, `'fr'` 같은 이상값 → null.
- `tests/architecture.test.ts`: 변경 없음. `game/quiz.ts` 의 `import type { Locale }` 은 값 import 가 아니라 위반이 아님 (규칙은 render/ui/document/window/localStorage/Math.random).
- 수동: 로비 토글로 EN 전환 → 모든 탭·로드아웃·결과·퀴즈 영어, 새로고침 후 유지, KO 복귀. `navigator.language` 를 en 으로 한 새 프로필에서 첫 진입이 영어.
